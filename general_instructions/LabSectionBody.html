This section contains three blocks of 10 periods. Each starts with 100 equipment units and a separate 1000-point wallet. Your group of six remains together within a block and is rematched between blocks.

{{ if is_policy }}

The underlying Main rule and report information from the preceding section continue unchanged. The new feature is policy redistribution at the Main Check. Voluntary costs and the Follow-up rule do not change.

{{ endif }}

Main Check: after period 5

{{ if is_fixed }}

Every participant with positive equipment after their period-5 voluntary decision pays 175 + 0.5 × their own equipment. At zero, the Main fine is zero. For example, 50 units means a 200-point Main fine.

The six-person group average is shown for information. It does not determine your Main fine in the Fixed section. There is no group threshold in this section.

{{ else }}

The Main group average uses all six participants' equipment, including your own, after all period-5 voluntary decisions.

{{ if is_ambiguity }}

The threshold is an integer from 33 through 47. You do not know this block's realized threshold before the Main Check. No probability distribution over these values is provided. It is revealed only after all six participants have completed their period-5 decisions.

The target succeeds only when the actual group average is strictly greater than the realized threshold. Equality does not satisfy the target.

{{ else }}

The known threshold is 40. The target succeeds only when the actual group average is strictly greater than 40. Exactly 40 fails; an average below 40 also fails.

{{ endif }}

If the target succeeds, nobody pays a Main fine. Otherwise, Main enforcement applies: each participant with positive equipment pays 175 + 0.5 × own equipment. A participant with zero equipment always pays zero. At 50 units, the fine when enforcement applies is 200 points.

{{ endif }}

Two starting reports

Before period 1 in every block, submit exactly two whole numbers from 0 to 100:

  1. Your planned equipment at the Main Check.
  2. Your expected group-average equipment at the Main Check, including you in the six-person average.

These reports are unincentivised: there is no payment for accuracy, and reports do not directly enter wallet calculations.

{{ if is_messages }}

Report 1 contributes anonymously to the public group report average. After all six members submit both reports, the average of report 1 alone is shown to all six throughout the block. Individual reports are not revealed. Report 2 remains private and is not included in this public average.

The display is labelled “Average reported planned Main-Check equipment”. It describes reported plans, not actual realized equipment. The public group report average does not mechanically change fines, transfers or payoffs.

{{ else }}

Both reports remain private; neither report is publicly disclosed.

{{ endif }} {{ if is_policy }}

Policy redistribution

After Main enforcement is determined, the six participants' actual Main fines are added to a group fine pool. Only these actual Main fines enter the pool: voluntary costs, Follow-up fines and automatic-retirement costs do not.

Eligible recipients are participants whose equipment is exactly zero immediately after their period-5 voluntary decision. If there is at least one eligible recipient, {{ policy_share }} of the fine pool is redistributed equally among them. Other participants receive no transfer. If no participant is eligible, actual redistribution is zero. If the fine pool is zero, all transfers are zero.

Fine payers pay their ordinary Main fine once. Redistribution comes from those already-paid fines; there is no additional charge. Any transfer is added to its recipient's wallet.

Example: two participants have zero equipment and the other four each have 40. The group average is below the threshold, so each positive-equipment participant pays 195. The actual fine pool is {{ example_pool }} points. With the configured share of {{ policy_share }}, {{ example_redistribution }} points are redistributed and each of the two recipients receives {{ example_transfer }} points. Example amounts are rounded for readability if needed; actual accounting uses unrounded amounts.

{{ endif }}

Follow-up: after period 10

After your period-10 voluntary decision, if your equipment is zero, there is no Follow-up fine, forced retirement or forced-retirement cost.

If equipment is positive, you pay a 75-point Follow-up fine. All remaining equipment is automatically retired, costing 0.10 × remaining equipment². Final equipment becomes zero. This automatic cost is separate from the cost of your voluntary decision.

{{ if is_policy }}

Follow-up fines and automatic-retirement costs never create a policy pool or another transfer.

{{ endif }}

Your final wallet for each block remains visible in your own block summary. The next block starts independently with 100 equipment units and a 1000-point wallet.
